## Delivered outcome

The owner can sign in through OIDC, create an allowed project, configure the protected runtime credential, select available model/effort/permission settings, and conduct a persistent text conversation. The React UI, authenticated Fastify API, PostgreSQL, pg-boss supervisor, and pinned Codex adapter are implemented. Browser closure or an API restart leaves healthy supervisor work running. Approval/input answers, cancellation, replay resynchronization, uncertainty, process inspection, storage visibility, logout, and emergency stop have explicit behavior.

The runtime boundary uses Codex 0.153.4 over private stdio, pinned generated schemas, generation fencing, restricted Linux containers, and a fixed HTTP model gateway. Managed XFS project slots provide actual hard byte/inode limits for workspaces and native state. Owner credentials are encrypted and managed through private supervisor/storage services; identity changes invalidate old browser grants, and credential removal requires confirmed runtime retirement.

The [user guide](../user/conversations.md), [developer workflow](../developer/development.md), and [Linux verification guide](../developer/linux-verification.md) describe the available paths. Portable release/restore and the remaining feature proposals are not established by this foundation report.
