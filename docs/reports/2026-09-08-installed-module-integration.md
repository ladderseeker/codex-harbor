# Installed file, terminal and deployment integration

Delivery is in progress. This report records the cumulative P004/P006/P009 implementation and preserves intermediate evidence; independent integration review and the final candidate checks remain pending. Protected off-host backup/restore and dedicated-account live gates remain separate and blocked. No repository initialization or protected transfer was performed.

The integration extends the fixed deployment registry with file operations, inspections, audits/events and terminal input/output/history. The installed API remains unprivileged; bounded file reads use the existing storage service's private `/files` endpoint. File mutation runs in the trusted supervisor with the immutable manifest's pinned helper image. Terminal purpose and its reviewed seccomp derivative remain pinned. Maintenance freezes queued file/terminal dispatch and new control/input, retains those queues without waiting forever for prohibited work, and permits bounded inspection/release/termination. Exact helper slots and terminal/background identities are retired before inventory. An explicit administrator retry of uncertain terminal retirement preserves the original record and respects its three-attempt limit.

Fresh restore metadata keeps original outcomes in the historical ledger, invalidates source file inspections, changes reservation/generation fences, revokes terminal controller/input authority and leaves unresolved effects requiring explicit destination reconciliation. Source launcher ledgers remain historical and never become destination authority. Terminal native directories are included in whole quota-unit publication, while native authentication and live lock files remain excluded. These semantics are canonical in [D006](../../design/decisions/006-portable-release-and-restore.md#p004p006-installed-module-integration--8-september-2026).
