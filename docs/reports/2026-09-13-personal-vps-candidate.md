## Outcome and status

[P015](../../design/proposals/archive/015-personal-vps-workspace.md) now has a candidate implementation for authenticated HTTPS, native subscription state, administrator-approved original project folders, and persistent conversations. P015 remains In progress: no owner-configured public installation or actual subscription conversation has been completed on this VPS. The [acceptance issue](../../issues/2026-09-13-130622-personal-vps-acceptance.md) owns those remaining gates. [D011](../../design/decisions/011-personal-vps-workspace.md) records the explicit personal trust model; managed P009 restore and broader proposal gates are not closed.

The dedicated nonroot native profile rejects local/fixture/managed combinations, requires HTTPS OIDC and a loopback backend, confines folder registration to canonical approved roots, supports selecting an exact root without moving it, and disables unsupported managed operations. Native credentials remain instance-private and native child environments are allowlisted. The separate deployment renderer generates root-owned service configuration, resource limits, private PostgreSQL and optional routing through the existing Traefik Docker provider. Official device login runs as the dedicated service account with API/supervisor stopped. No root coding runtime, Docker socket or unrestricted sandbox fallback is introduced.
