# P002 API-token implementation evidence

Recorded 7 September 2026. P002 is **Accepted / Implemented**. Two independent review rounds closed with no remaining actionable findings. Required live-account and applicable upstream gates remain open, so the proposal stays active.

## Delivered outcome

The owner can create and revoke project-scoped tokens through the real browser interface. External clients use the protected versioned API and SSE with explicit read, execute, approve, and cancel grants, an execution ceiling, and expiry. Raw secrets appear only in the first successful creation response; durable records contain a verifier and metadata. Revocation closes streams and denies new dispatch while preserving already-authorized work.

See the [canonical proposal](../../design/proposals/002-programmatic-api-access.md), [user guide](../user/api-tokens.md), and [API guide](../developer/programmatic-api.md) for scope and available behavior.

## Independent review

Round 1 found a high-severity control-lifecycle defect: revocation immediately before an approval or cancellation send could close the healthy original runtime. It also found unconditional Origin requirements in bearer documentation and a UI retry state that prevented editing after definitive rejection.

The fixes distinguish a proven pre-wire authority denial from uncertain delivery. A denied approval stays answerable by the owner, denied cancellation leaves the original grant active, and queued cancellation retains its authority lock through the mutation transaction. OpenAPI makes Origin/CSRF conditional on cookie authentication. Definitive request errors allow correction; uncertain responses retain the original retry intent.

Round 2 independently checked those changes and their evidence. E2E pauses actual supervisor database locks, revokes the token before sending, and verifies that the same waiting runtime/generation remains usable through an owner answer. Focused adapter contracts prove no interrupt was sent after denied authority and the native approval remains restorable. The reviewed source matches the stable E2E digest. No actionable findings remain in P002's review scope.
