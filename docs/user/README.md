# User guides

Harbor's conversation, API-token and workspace features are implemented with required verification gates still open. These guides describe the available interface; the [proposal index](../../design/proposals/README.md) and [issue index](../../issues/README.md) show remaining delivery gates.

- [Conversations and account setup](conversations.md): owner login, project selection, text requests, approvals, cancellation, storage visibility, and reconnect behavior.
- [API tokens](api-tokens.md): create, limit, and revoke credentials for external clients.
- [Projects and workspaces](workspaces.md): choose Local, Git Worktree or Copy, coordinate conversations and recover an uncertain reservation.
- [Developer setup](../developer/development.md): disposable local instance and current runtime prerequisites.
