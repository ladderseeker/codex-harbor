# Issue inbox

This folder is an unprioritized inbox of concrete problems and missing evidence. Browse the [active folder](.) or run `rg --files issues -g '*.md' -g '!issues/archive/**' -g '!README.md'` from the repository root. The [archive folder](archive) retains resolved, transferred or retired history. Filenames are stable record identities, not a priority order.

Each active record carries evidence, impact, a recheck path and its current inbox ownership. Select work through a new cohesive proposal under the [workflow](../design/workflow.md#issue-resolution-and-transfer); finding an issue is not authorization to execute it. An unavailable gate remains unverified. Historical metadata inside a record is not a current queue.

The 20 September migration returned unresolved legacy proposal obligations to this inbox, including the reopened runtime-compatibility record and two deferred complete-outcome records. Folder contents are the discovery source; there is no manually maintained per-record status table. See the [proposal folder](../design/proposals) and [current systems](../design/systems) for selected plans and design ownership.
