## Evidence — 8 September 2026

The early trusted relay bridge checked the durable launched/verified state and exact running container identity, but omitted the worker's absolute deadline. Unlike ordinary `worker.invoke`, it could select Docker execution for an expired worker while retirement was still pending. Individual connection timers did not impose the remaining whole-worker lifetime.

Main reproduced that selection against bridge SHA-256 `531ba74188159719ecb61a235565175a19b338e003ef98a79413d1bce73385b3` using an expired synthetic receipt and fixed test modules. The execution boundary was intercepted: no Docker process, network operation or real privilege was used. The exact observed source and result are retained in `.test-runs/p010-relay-bridge-original.py` and `p010-relay-deadline-20260908.json`. The viewer layer was not connected at this checkpoint; this is a source-boundary finding, not a claim of an exposed application exploit.
